# 우즈베키스탄/CIS 맥락 — 레퍼런스 보드 (uz-reference-board)

한국 표준(4레인 출처 격리·기본 6장·L1/L2 2단계·direction-only)은 그대로 적용하고, 아래는 우즈베키스탄·CIS 시장에서 보드를 만들 때 추가로 고려하는 항목입니다.

## 용어 병기(RU/UZ)

| 한국어 | RU | UZ |
|---|---|---|
| 레퍼런스 보드 | референс-борд / мудборд | referens taxtasi / moodboard |
| 레퍼런스 이미지 | референсные изображения | referens rasmlar |
| 방향 참고 전용 | только как ориентир | faqat yo'nalish uchun |
| 검색어 | поисковый запрос | qidiruv so'rovi |

## 레인 운영 시 현지 특이점

- 검색어는 한국 표준과 같이 영문 L1/L2를 유지합니다(`Food Photography` → `Plov Photography` 같은 직접 L2는 taxonomy에 없으면 L1에서 멈춤). RU/UZ 검색어로 바꾸면 Pinterest·아카이브 결과 풀이 급격히 줄고 미러 사이트가 섞이므로 권장하지 않습니다.
- Pinterest 레인에서 CIS 지역 Pin은 아웃바운드가 VK·Telegram·Yandex Zen으로 향하는 경우가 많습니다. 어떤 경우에도 따라가지 않습니다(공통 규칙).
- `award-ad` 레인은 Ads of the World에서 국가 필터(Uzbekistan·Kazakhstan·Russia)를 검색어가 아닌 라우팅 메타데이터로만 씁니다. 검색어에 국가명을 붙이지 않습니다.
- 현지 플랫폼(Uzum Market·Yandex Market·OLX.uz·Telegram 채널)의 상품 이미지는 레퍼런스 출처가 아닙니다. 요청이 있어도 4레인 밖이므로 "범위 밖"으로 처리합니다.

## 현지 장면·문화 적합성 렌즈(순위 단계에서만)

후보 풀이 만들어진 뒤 다양성·적합성 판단에 다음을 반영합니다(검색어에는 넣지 않음).

- 장면: 마할라 골목, 초이호나(찻집) 상, 초르수 바자르 진열, 타슈켄트 지하철 역사, 논(빵) 화덕, 아틀라스 원단.
- 명절·계절: 나브루즈(3월), 라마단·하이트, 여름 40도 이상 더위(음료·냉방 카테고리).
- 색·소재: 청록·코발트 타일, 수자니 자수, 황토·햇빛 콘트라스트. 트렌드 팔레트를 쓰더라도 `trend_fit`에 현지 문화 적합성을 기록합니다.

## 우즈벡 광고법 관련 배제 기준

레퍼런스는 방향 참고 전용이지만, 그대로 옮기면 현지 광고법에 걸리는 장치는 `exclude_from_reference`에 미리 적어 둡니다(법률 자문 아님).

- 풍기문란·과도한 노출 표현: 수영복·속옷 카테고리라도 공공 광고 기준이 한국보다 보수적.
- 비교 광고: 경쟁 브랜드를 직접 지목하는 장치는 배제.
- 외국어 표기: 광고 텍스트는 국가어(UZ) 우선, RU 병기 규정. 레퍼런스의 영문 헤드라인 배치는 "카피 존" 구조로만 전이.
- 주류·담배·의약품·금융 상품은 별도 표시 규정이 있으므로 해당 카테고리 레퍼런스의 카피 장치는 전이하지 않습니다.

## 핸드오프

현지화된 카피·구성은 `gil-creative:market-profile-engine`(시장 프로필)과 `gil-creative:creative-architect`(RU/UZ/KR 병렬 CreativeSpec)로 넘깁니다. 게시 전 법규 검토는 `gil-creative:publication-review`(설치 시).
