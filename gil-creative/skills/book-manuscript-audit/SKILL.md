# 도서 원고·제안서 검수

원본을 수정하지 않고 원고, 목차, 초안, 출판 제안서와 출처를 대조한다.

- 장마다 인물 이름·관계·외형, 사건 시점, 세계 규칙, 서술 시점이 일치하는지 위치별로 확인한다.
- 윤문 전후 고유명사·숫자·날짜·인용이 보존됐는지 확인한다. 한국어 문체 결함은 `gil:humanize-korean` 기준과 대조한다.
- 식별 가능한 타 작품과 유사한 구절·대사가 있으면 근거와 함께 위험으로 기록한다. 확인 자료 없이 표절이라고 확정하지 않는다.
- 목차와 챕터, 장르·독자 수준, 분량 기준이 맞는지 확인한다. 제안서에 콘셉트·목표 독자·목차·샘플 챕터·저자 소개·마케팅 계획이 있는지 본다.
- 출판사·공모전·인세·투고 기한을 실제 현재 출처와 대조한다. 확인되지 않은 출판 정보는 미검증으로 남긴다.

보고서는 `판정(PASS/FAIL/미확인)`, `확인 자료`, `원고 요소별 첫 표현·후속 표현`, `심각도·위치·근거가 있는 발견`, `미검증 항목`으로 작성한다. 원본이나 출처가 없으면 해당 범위를 PASS로 판정하지 않는다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.

## GIL 연결 (v2.5.0)

- **검수 대상 산출물**: `gil-creative:book-chapter-writer` · `gil-creative:book-revision-coach` · `gil-creative:book-proposal-writer` · `gil-creative:book-outline-designer` · `gil-creative:book-publisher-matcher`
- **◆최종본 게이트**: 에이전트 `gil-creative:content-publishing-pipeline`가 ◆최종본을 마감하기 전에 이 검수를 1회 실행한다. ⚡초안·◐작업본에는 자동으로 붙이지 않는다(common-rules §1 등급제).
- **판정 규칙**: 같은 세션에서 산출물을 만든 주체의 자기 검수는 `자체 검수`로 표기하고 독립 감사라고 부르지 않는다. 확인 불가 항목은 `미확인`으로 분리해 PASS에 섞지 않는다.
- **보고서 한국어 품질**: 검수 보고서 자체가 ◆최종본으로 외부 전달되면 `gil:ai-slop-reviewer` → `gil:humanize-korean` 체인을 적용한다.
