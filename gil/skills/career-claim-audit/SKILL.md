# 커리어 자료 주장 검수

지원자가 제공한 이력과 산출물을 읽기 전용으로 대조한다.

- 모든 경력·프로젝트·성과·자격 주장이 지원자의 자료에서 확인되는지 기록한다. 채용공고에 맞춘 표현 변경과 실제로 갖지 않은 역량 주장 사이를 구분한다.
- 성과 숫자가 원자료에 없는 경우 발명이라고 단정하기 전에 근거 부재로 표시하고 확인을 요청한다. 날짜·재직 기간·직함이 여러 산출물에서 일치하는지 대조한다.
- 모의면접 답변에 허구의 STAR 사례, 허위 공백 사유, 기만적 답변이 들어갔는지 확인한다.
- 지원자·제3자의 개인정보가 목적에 비해 과도하게 포함됐는지 확인한다. 급여·경쟁률 등 시장 수치는 출처와 기준 시점을 확인한다.

보고서는 `판정(PASS/FAIL/미확인)`, `확인 자료`, `주장별 근거`, `위치·근거가 있는 발견`, `미검증 항목`으로 작성한다. 주장별로 산출물의 위치, 지원자의 원자료, 뒷받침 여부를 대응시킨다. 모든 경력·수치·날짜 주장이 원자료로 확인된 경우에만 전체 사실성을 PASS로 판정한다. 미검증 주장이 하나라도 있고 확인된 모순은 없으면 전체 사실성을 `미확인`으로 판정한다. 확인된 경력·수치 날조나 기만적 면접 답변은 FAIL로 판정한다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.

## GIL 연결 (v2.5.0)

- **검수 대상 산출물**: `gil:resume-builder` · `gil:portfolio-guide` · `gil:interview-coach` · `gil:job-analyzer`
- **◆최종본 게이트**: 에이전트 `gil:career-job-search-coordinator`가 ◆최종본을 마감하기 전에 이 검수를 1회 실행한다. ⚡초안·◐작업본에는 자동으로 붙이지 않는다(common-rules §1 등급제).
- **판정 규칙**: 같은 세션에서 산출물을 만든 주체의 자기 검수는 `자체 검수`로 표기하고 독립 감사라고 부르지 않는다. 확인 불가 항목은 `미확인`으로 분리해 PASS에 섞지 않는다.
- **보고서 한국어 품질**: 검수 보고서 자체가 ◆최종본으로 외부 전달되면 `gil:ai-slop-reviewer` → `gil:humanize-korean` 체인을 적용한다.
