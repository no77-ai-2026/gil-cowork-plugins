# 문서·수치 검수

원본을 수정하지 않고 산출물과 제공된 자료를 대조한다.

- 통계마다 식별 가능한 출처와 기준 시점을 확인한다. 공공데이터의 원천 진위까지 필요한 경우 `gil:validate-data`의 출처 대조(Provenance) 섹션 기준으로 별도 확인한다.
- 차트·SVG 라벨·표·요약문의 값, 단위, 축 범위와 날짜가 원자료와 일치하는지 확인한다. 합계·증감률·평균·단위 변환을 다시 계산한다.
- 파일 확장자와 실제 형식, 공문서의 수신·본문·붙임, 번호와 날짜 표기가 목적에 맞는지 확인한다.
- 주민등록번호·연락처·개인 주소·계좌번호가 불필요하게 노출됐는지 확인한다. 자료 조회·파싱 실패를 추정값으로 채우지 않았는지 본다.

보고서는 `판정(PASS/FAIL/미확인)`, `확인 자료`, `수치별 재계산`, `심각도·위치·근거가 있는 발견`, `미검증 항목`으로 작성한다. 원자료가 없으면 정합성을 PASS로 판정하지 않는다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.

## 문서 입력 전처리 (v2.6.0)

입력이 HWP/HWPX/HML·PDF·DOCX·XLS(X)·스캔 이미지 파일이면 본문 작업 전에 **`gil:doc-reader`로 먼저 마크다운화**한다(원자료 대조). 권장 옵션: `--html-tables` 또는 `--format json`. 파싱 `warnings`(OCR 필요·숨김 텍스트·부분 파싱)는 결과에 그대로 옮긴다.

## GIL 연결 (v2.5.0)

- **검수 대상 산출물**: `gil:docx-generator` · `gil:pptx-designer` · `gil:xlsx-creator` · `gil:html-report` · `gil:html-slide` · `gil:hwpx-writer` · `gil:pdf-writer`
- **◆최종본 게이트**: 에이전트 `gil:core-text-qa-coordinator`가 ◆최종본을 마감하기 전에 이 검수를 1회 실행한다. ⚡초안·◐작업본에는 자동으로 붙이지 않는다(common-rules §1 등급제).
- **판정 규칙**: 같은 세션에서 산출물을 만든 주체의 자기 검수는 `자체 검수`로 표기하고 독립 감사라고 부르지 않는다. 확인 불가 항목은 `미확인`으로 분리해 PASS에 섞지 않는다.
- **보고서 한국어 품질**: 검수 보고서 자체가 ◆최종본으로 외부 전달되면 `gil:ai-slop-reviewer` → `gil:humanize-korean` 체인을 적용한다.
