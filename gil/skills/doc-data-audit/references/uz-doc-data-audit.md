# UZ 듀얼 — doc-data-audit 우즈베키스탄 추가 기준 (GIL 오리지널)

UZ 공문서·보고서는 날짜 형식(DD.MM.YYYY)·숫자 구분자(공백 천 단위, 쉼표 소수점)·통화 표기(so'm/UZS)가 한국식과 섞이지 않았는지 확인한다. 러시아어·우즈베크어 병기본은 두 판본의 수치를 모두 대조한다.

## 공통
- 우즈베크어(라틴)·러시아어(키릴) 병기본은 두 판본을 모두 대조하고, 한쪽만 확인했으면 `미확인`으로 둔다.
- 현지 법령·기관 기준은 원문 확보 상한(정보원 3곳·총 5회, `gil:contract-review` `references/source-access-notes.md`) 안에서만 확인한다.
