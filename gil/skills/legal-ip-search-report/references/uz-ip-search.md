# UZ 듀얼 — 우즈베키스탄 특허·상표 선행조사 (GIL 오리지널)

`gil-mcp-ip`는 우즈베키스탄 소스를 제공하지 않는다. UZ 조사는 **공식 공개 검색 화면 + 검색식·열람 범위 기록**으로만 수행하고, 인증된 API 조사라고 쓰지 않는다.

## 출발점 (조사 시점에 현행 주소를 다시 확인)
- 우즈베키스탄 지식재산청(Intellektual mulk agentligi, 법무부 산하) 공개 DB·공보 — 상표·특허·실용신안·디자인 등록 공보
- WIPO Global Brand Database / PATENTSCOPE — 마드리드 경유 UZ 지정 상표, PCT 국내단계 진입 여부
- 러시아어·우즈베크어(라틴·키릴) 표기 변형을 함께 검색한다 (예: 브랜드명의 키릴 음역, 라틴 음역 2종)

## 조사 원칙
1. 상표는 니스 분류 기준 지정상품을 한국 조사와 동일하게 맞춘다. 현지 유통 상품명(러시아어 병기)을 확인한다.
2. 마드리드 의정서 경유 출원 가능 여부와 직접 출원(현지 대리인 필요)을 구분해 적는다.
3. 공보 열람 범위(기간·분류)와 미조사 범위를 보고서 "한계"에 명시한다.
4. 원문 확보 시도는 정보원 3곳·총 5회 상한(`gil:contract-review` `references/source-access-notes.md`와 동일). 접근 불가면 2차 출처로 표시(`SECONDARY`).
5. 결과 0건은 등록 가능·침해 없음의 근거가 아니다 — 한국 조사와 같은 원칙.

- "Uzbekistan에 우리 브랜드 상표 먼저 등록된 게 있나 봐줘"
