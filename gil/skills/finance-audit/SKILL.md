# 재무 산출물 검수

원본 파일이나 외부 회계 시스템을 수정하지 않고 근거 자료와 산출물을 대조한다.

- 합계, 대차 평형, 세액, 마진, 성장률, 밸류에이션 배수를 입력값에서 다시 계산한다. 재계산에 사용한 식과 값을 기록한다.
- 재무상태표의 자산 = 부채 + 자본을 확인하고, 손익·자본변동·현금흐름 및 주석의 연결 숫자를 대조한다. 자료가 없으면 그 부분은 미검증이다.
- 외부 숫자는 공시 번호·원장 항목·법령·해당 연도 요율표까지 추적한다. 과세 연도가 다른 자료를 현재 기준으로 쓰지 않는다.
- 전망과 실적이 구분됐는지 확인한다. 세무·회계 산출물에 "세무사·회계사 자문을 대체하지 않는 참고 자료입니다."라는 고지가 있는지 확인하고, 빠졌으면 중대 발견으로 기록한다. 전문가 자문을 대체한다고 표현하지 않는다.

보고서는 `판정(PASS/FAIL/미확인)`, `자료와 기준 연도`, `위치·근거가 있는 발견`, `재계산 표`, `미검증 항목`으로 작성한다. 계산 오류나 근거 없는 핵심 수치는 FAIL로 기록하고, 자료가 없다는 이유로 PASS를 내리지 않는다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.

## 문서 입력 전처리 (v2.6.0)

입력이 HWP/HWPX/HML·PDF·DOCX·XLS(X)·스캔 이미지 파일이면 본문 작업 전에 **`gil:doc-reader`로 먼저 마크다운화**한다(검수 대상 표). 권장 옵션: `--html-tables`. 파싱 `warnings`(OCR 필요·숨김 텍스트·부분 파싱)는 결과에 그대로 옮긴다.

## GIL 연결 (v2.5.0)

- **검수 대상 산출물**: `gil:financial-statements` · `gil:close-management` · `gil:variance-analysis` · `gil:tax-helper` · `gil:investor-relations`
- **◆최종본 게이트**: 에이전트 `gil:finance-report-assembler`가 ◆최종본을 마감하기 전에 이 검수를 1회 실행한다. ⚡초안·◐작업본에는 자동으로 붙이지 않는다(common-rules §1 등급제).
- **판정 규칙**: 같은 세션에서 산출물을 만든 주체의 자기 검수는 `자체 검수`로 표기하고 독립 감사라고 부르지 않는다. 확인 불가 항목은 `미확인`으로 분리해 PASS에 섞지 않는다.
- **보고서 한국어 품질**: 검수 보고서 자체가 ◆최종본으로 외부 전달되면 `gil:ai-slop-reviewer` → `gil:humanize-korean` 체인을 적용한다.
