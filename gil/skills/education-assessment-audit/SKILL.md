# 교육 산출물 검수

원본을 수정하지 않고 학습 목표, 문제, 답안, 인용 자료를 대조한다.

- 각 문항이 어떤 학습 목표를 평가하는지 연결하고 평가되지 않은 목표를 찾는다. 목표와 관계없는 문항도 기록한다.
- 정답과 해설은 수학·코드·사실 확인 등 필요한 방법으로 독립 재풀이한다. 재풀이할 자료가 없으면 정답을 PASS로 판정하지 않는다.
- 문항 난이도가 선언된 학습자 수준과 맞는지 확인한다. 차시 합계, 선수 과목 순서, 채점 비중과 일정도 다시 계산한다.
- 논문·저자·학술지·연도를 실제 검색 기록이나 원문과 대조한다. 찾지 못한 인용은 미확인으로 남긴다.

보고서는 `판정(PASS/FAIL/미확인)`, `확인 자료`, `목표·문항 대응표와 재풀이`, `심각도·위치·근거가 있는 발견`, `미검증 항목`으로 작성한다. 핵심 근거가 없으면 해당 범위를 PASS로 판정하지 않는다. 독립된 검수자를 실행하지 않았다면 독립 감사라고 부르지 않는다.

## GIL 연결 (v2.5.0)

- **검수 대상 산출물**: `gil:assessment-creator` · `gil:curriculum-designer` · `gil:learning-material` · `gil:textbook-builder` · `gil:past-exam-analyzer`
- **◆최종본 게이트**: 에이전트 `gil:education-course-builder`가 ◆최종본을 마감하기 전에 이 검수를 1회 실행한다. ⚡초안·◐작업본에는 자동으로 붙이지 않는다(common-rules §1 등급제).
- **판정 규칙**: 같은 세션에서 산출물을 만든 주체의 자기 검수는 `자체 검수`로 표기하고 독립 감사라고 부르지 않는다. 확인 불가 항목은 `미확인`으로 분리해 PASS에 섞지 않는다.
- **보고서 한국어 품질**: 검수 보고서 자체가 ◆최종본으로 외부 전달되면 `gil:ai-slop-reviewer` → `gil:humanize-korean` 체인을 적용한다.
