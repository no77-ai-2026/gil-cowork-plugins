# UZ 듀얼 — commerce-margin-audit 우즈베키스탄 추가 기준 (GIL 오리지널)

UZ 채널(Uzum·OLX·Telegram·Yandex)은 채널 수수료·배송 모델·UZS 가격 반올림 관행을 해당 채널 스킬(`gil-commerce:marketplace-uzum` 등)의 현재 기준과 대조한다. 기준 확인 불가면 채널 준수 PASS를 내지 않는다.

## 공통
- 우즈베크어(라틴)·러시아어(키릴) 병기본은 두 판본을 모두 대조하고, 한쪽만 확인했으면 `미확인`으로 둔다.
- 현지 법령·기관 기준은 원문 확보 상한(정보원 3곳·총 5회, `gil:contract-review` `references/source-access-notes.md`) 안에서만 확인한다.
